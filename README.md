# Max Code releases

Installers for **Max Code**, an AI code editor with the built-in agent Max.

This repository only contains release downloads. It does not contain source code.

## Install (Windows 10/11, 64-bit)

1. Open the [latest release](https://github.com/mlrgamestudios/max-code-releases/releases/latest).
2. Download `MaxCodeSetup-x64-<version>.exe` and run it. It installs for the current user, so no admin rights are needed.
3. The installer isn't code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Click **More info**, then **Run anyway**.

Max Code updates itself. It checks for new versions at startup and every few hours, and you can also use **Max Code: Check for Updates...**. When an update is found, click **Update Now**.

`latest.json` in each release is the update manifest the app reads.
